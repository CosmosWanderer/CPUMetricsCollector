# CPUMetricsCollector

## Использование
### Для работы инструмента требуется:
1. Подключить в файлы с main-функцией и тестируемой функцией заголовочный файл "__perf_metrics.h"
2. В начале main-функции инициализоварть работу счетчиков
```c
#include "__perf_metrics.h"

int main() {
    perf_global_init("metrics.csv");

    ...
}
```
3. Проинструментировать тестируемую функцию в точке входа и в точках выхода методами из заголовочного файла
```c
#include "__perf_metrics.h"

void function() {
    static perf_ctx ctx;
    perf_start(&ctx);
 
    ...

    if (exit_early) {
        perf_stop(&ctx);
        perf_write(&ctx);
        return;
    }

    ...


    perf_stop(&ctx);
    perf_write(&ctx);
}
```
### Сборка
Тестируемая система: linux mint 22.3
Для работы инструмента требуется установленный linux perf

Команда для сборки:
```bash
gcc -DSPEC_CPU -DSPEC_CPU_LINUX *.c -o Test -lm
```

Команда для запуска:
```bash
sudo ./Test 513
```

Если нужно конкретизировать, какие и сколько ядер процессора использовать:
```bash
sudo taskset -c 0-3 ./Test 513
```

### Результат работы
В качестве результата в директории программы создаётся .csv файл. Название файла определяется аргументом функции ```perf_global_init("metrics.csv")```
Первая строчка содержит список собираемых метрик. Последующие строчки содержат собранные метрики для каждого вызова тестируемой функции.
